100,001個目の optionいけにえ

options.length に大きな数を代入すると、
足りない分だけ option が勝手に生えてきます。

If the given value is greater than 100,000, then return.
— HTML Standard, 2.6.3

上限は 10万個。例外も投げずに return。

DevTools のコンソールで唱えてください。
document.querySelector('select').options.length = 100001
何も起きません。
