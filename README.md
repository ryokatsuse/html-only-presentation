# HTML　Only Presentation

## 👻 HTMLの怪談話(階段話)

CSS・JavaScriptを一切使わず、**HTMLだけ**で作られたプレゼンテーションです。
「階段(かいだん)」を一段のぼるごとに、HTMLパーサーにまつわる「怪談(かいだん)」を一話ずつ語ります。

### 見方

`index.html` をブラウザで開き、各ページ下部のリンクでスライドを進めてください。
